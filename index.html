capabilities

It doesn't just open apps.
It operates them.

Five flags, one wake word. Everything below runs from a single spoken sentence.

--wake-word

True hands-free automation

Wakes on "Hey Barvis" and executes the full command end to end. No clicking, no tapping, no reaching for a keyboard.

--in-app-context NEW

In-app context awareness

Goes beyond launching apps to operating inside them — finding a title in the App Store, hitting "Sign In" in Chrome, typing an email into a field.

--chain

Smart compound commands

Understands chained natural-language instructions, like "open Chrome, then search Star Wars, then click the first link" — as one continuous action.

--system

Deep system integration

Jumps straight to macOS Settings panes — Wi-Fi, Bluetooth, Displays — controls volume and brightness, and sends iMessages or emails on your behalf.

--spotify

API-backed Spotify control

Uses the official Spotify API to find and play the exact song, album, or artist you asked for, entirely in the background.

architecture

How it listens, thinks, and acts

A signal chain, not a monolith. Each stage has a primary provider and a local or fallback path, built in Python 3.10+.

01 · EAR
Speech-to-Text
Google Speech Recognition API converts your voice into text.
02 · BRAIN
Intent Parsing
Groq API running Llama 3 for fast natural-language understanding, with Google Gemini as fallback.
03 · HANDS
OS Automation
AppleScript (osascript) injected dynamically to drive System Events, Chrome, Spotify, Finder, and Notes, plus direct DOM injection for clicks and form fills.
04 · VOICE
Text-to-Speech
ElevenLabs API for a realistic AI voice, with pyttsx3 as a fully offline fallback.
core: Python 3.10+ · macOS only (relies on AppleScript / System Events)
origin

Why this exists

Siri can open Spotify. It can't play the actual song you asked for, half the time. Same story with most "voice assistants" — they launch an app and leave you to do the rest by hand. That gap is basically the whole reason Barvis exists.

The idea was simple: if I can say it, the computer should be able to do it — not just get me to the right screen. So Barvis doesn't stop at opening Chrome. It searches inside Chrome. It doesn't stop at opening Settings. It clicks through to Bluetooth. It's less "assistant" and more a pair of very fast, very obedient hands wired to a language model.

It's a solo project, built for one very specific use case — a hands-free macOS setup — and shared in the open because someone else is probably tired of clicking through the same five steps too.
